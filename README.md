# meer21cm workshop notebooks

Notebooks for the meer21cm hands-on session at 21cm & Cosmological Lines 2026 (INPE).

- `hi_vs_galaxy_survey.ipynb`: a simulated HI intensity map (with a MeerKAT-like beam) compared with a galaxy catalogue binned into HEALPix number counts, for 0.4 < z < 0.6 over an 80 x 30 deg patch.

Requires [meer21cm](https://github.com/meerklass/meer21cm) ([docs](https://meer21cm.readthedocs.io/en/latest/)).
