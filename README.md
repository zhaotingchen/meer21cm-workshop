# meer21cm workshop notebooks

Notebooks for the meer21cm hands-on session at 21cm & Cosmological Lines 2026 (INPE).

1. `mock_simulation_basics.ipynb`: simulate a matter and HI field in a box and measure a power spectrum.
2. `hi_vs_galaxy_survey.ipynb`: one mock universe observed as an HI intensity map and as a galaxy survey, with foreground cleaning and a model comparison.
3. `meerklass_2019_data.ipynb`: MeerKLASS 2019 L-band data cross-correlated with WiggleZ galaxies. Needs two data files in `data/` (see the notebook) and takes about 12 min.

Requires [meer21cm](https://github.com/meerklass/meer21cm) ([docs](https://meer21cm.readthedocs.io/en/latest/)). The notebooks can be presented as slides with [RISE](https://github.com/jupyterlab-contrib/rise).
